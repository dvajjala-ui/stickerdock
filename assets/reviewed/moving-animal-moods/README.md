# Moving Animal Moods — reviewed portable pack

This is a three-sticker GENERAL/ANIMATED StickerDock pack, prepared for private
Admin review. `pack.zip` is the exact portable archive; `references.json` lists
the source for each sticker in manifest order. The archive is 668,072 bytes,
SHA-256 `c22c5c63db1bc772c79aba05a68b57e343f2c21a952fa4f86cea4f33240351fc`.
No source video or secret is stored here.

Each sticker is a 512×512 animated WebP below 500 KB. The pack passed the
public archive validator and four-frame visual contact-sheet review for each
clip. The Husky clip was shortened after a later frame cropped its face.
Source SHA-256 values are in `references.json`; the video originals are linked
above. The working conversion used FFmpeg at 8 fps and Pillow's WebP encoder.

Import through Admin → Sticker packs → Import ZIP with these two files. Import
creates only a private draft. Inspect all moving frames, credits and captions
before marking it reviewed and publishing. A public catalog read-back and phone
acceptance are separate checks.
