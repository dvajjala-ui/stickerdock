A native Android sticker library with a separate private creative workspace. Import your existing stickers, turn images into funny reactions, organize packs and add them to WhatsApp or WhatsApp Business.

What works today

StickerDock supports personal image/folder/ZIP import, static artwork editing, captions, search, categories, backup and pack sharing. Creator Studio and the owner admin can upload sources, queue AI-assisted captions, review drafts and publish general-audience packs to the Android catalog.

Groq analyzes selected source images and suggests short captions. Local rendering produces WebP stickers. This is not a claim of custom AI image synthesis or access to another app's full catalog.

Pinterest connection

The optional integration requests read-only access to the authenticated owner's boards and Pins through official OAuth. Admin reads these live and links back to Pinterest. Pinterest access requires platform approval. StickerDock does not archive Pin data or images, train models using Pinterest content, or turn Pins into distributable stickers. Meme generation uses independently uploaded or licensed sources instead.

Personal library privacy

Phone imports stay on the phone. There is no automatic upload of the Android database. Optional private cloud reference-library sync is a planned feature; it is not enabled by importing a WhatsApp folder.
